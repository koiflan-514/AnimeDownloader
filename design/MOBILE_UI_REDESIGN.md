# AnimeDownloader Android 移动端 UI 重设计

> 对应设计稿：Ardot `AnimeDownloader Android 重设计`（fileId 728264962704172）

## 1. 设计目标

针对现有 Android 版本在手机上出现的**控件过大、文字折行、信息堆叠、底部操作冲突**等问题，重新梳理核心页面：

- **视觉干净简洁**：深色基调 + 单一强调色，去除多余的描边、渐变与装饰。
- **信息层级分明**：通过字号、字重与表面色阶区分「标题 / 控件 / 内容 / 辅助信息」。
- **交互易用**：底部主导航 + 悬浮主操作，关键控件符合 Android 44dp 触控目标。
- **适配手机窄屏**：所有筛选控件改用可滚动或自适应布局，杜绝文字竖排折行。

## 3. 全局导航模型

```
┌─────────────────────────────────────┐
│  状态栏（系统）                        │
├─────────────────────────────────────┤
│                                     │
│          页面内容（可滚动）           │
│                                     │
├─────────────────────────────────────┤
│  底部胶囊 Tab Bar                    │
│  [画廊]  [下载]  [设置]              │
└─────────────────────────────────────┘
```

- **底部主导航**采用悬浮胶囊 Tab Bar，固定 3 个一级入口：画廊、下载、设置。
- 每个 Tab 为 44dp 以上触控区域；当前页使用 `accent-soft` 底衬 + 强调色文字。
- 图片查看页为全屏沉浸式，不显示底部 Tab Bar，通过左侧边缘滑动或返回按钮退出。
- 设置页为二级页面，顶部显示返回按钮，底部 Tab Bar 仍然保留用于一级切换。

## 4. 核心页面

### 4.1 画廊主页（Screen 1）

```
┌────────────────────────────┐
│ AnimeDownloader              │
│ 灵感画廊              ≡    │
│ ┌──────────────────────┐ ┌─┐│
│ │ 标签搜索（空格分隔）  │ │⚙││
│ └──────────────────────┘ └─┘│
│ [Lolicon] [Catgirl*] [Waifu]│  ← 横向滚动源选择
│ [屏蔽] [随机*] [分页] [NSFW]│  ← 过滤芯片
│ ┌────┐  ┌────┐              │
│ │图1 │  │图2 │              │  ← 2 列网格
│ └────┘  └────┘              │
│ ┌────┐  ┌────┐              │
│ │图3 │  │图4 │              │
│ └────┘  └────┘              │
│                    [下载全部] │  ← 悬浮 FAB
│  [画廊*] [下载] [设置]       │
└────────────────────────────┘
```

**布局结构**

| 区域 | 组件 | 说明 |
|---|---|---|
| 顶部 | 应用标题块 + 菜单按钮 |  eyebrow `AnimeDownloader` 11dp，标题 `灵感画廊` 28dp Bold |
| 搜索 | 胶囊搜索框 + 筛选图标 | 占满宽度，右侧 44dp 圆形按钮 |
| 源选择 | 可横向滚动的 Pill | 当前源用 `accent-soft` 底衬 + 强调色描边；其余用 `bg-elevated` |
| 过滤 | 紧凑 Chip | 单行排列：屏蔽 / 随机 / 分页 / NSFW；激活态同强调色 |
| 内容 | 2 列网格 | 卡片 158dp × 196dp，间距 12dp；缩略图 140dp 正方形，下方作者名 + 分辨率 |
| 主操作 | 悬浮 FAB | 右下角，绿色底 + 加号图标 +「下载全部」|
| 导航 | 底部 Tab Bar | 3 个等宽 Tab |

**关键改进**

- 原方案把「源选择 + 过滤开关 + 搜索」挤在同一垂直空间，文字出现竖排折行。新方案把它们拆成**独立横向行**：源选择可滚动、过滤 Chip 自适应、搜索单独一行。
- 图片网格从「底部信息压顶」改为**卡片内 8dp 间距**，作者名和分辨率左右对齐，避免信息堆在图片下方。
- 底部「下载全部」大按钮与「共 N 张」状态合并为右下角 FAB，避免与底部 Tab Bar 冲突。

## 6. 与现有实现的对应关系

当前 Android 工程使用原生 `net10.0-android` + `RecyclerView`（见 `AnimeDownloader.App.csproj`）。重设计后建议按以下方式映射：

| 设计区域 | 推荐原生实现 |
|---|---|
| 源选择 / 过滤 Chip | `RecyclerView` + `LinearLayoutManager.HORIZONTAL`（Pills）/ `FlexboxLayoutManager`（Chips）|
| 图片网格 | `RecyclerView` + `GridLayoutManager`（spanCount = 2，根据屏幕宽度动态计算）|
| 设置分组 | `RecyclerView` + `LinearLayoutManager`，按 viewType 区分「带开关 / 带值 / 只读」|
| 底部 Tab Bar | 自定义 `FrameLayout` + 3 个 `LinearLayout` Tab，或用 `BottomNavigationView` 自定义样式 |
| 图片查看页 | 全屏 `Activity` / `FragmentDialog`，`ViewPager2` 实现左右滑动，双指缩放可用 `PhotoView` 或自定义 `ScaleGestureDetector` |
| 下载 FAB | `FloatingActionButton` 或自定义 `FrameLayout` 绝对定位 |

## 7. 适配要点

1. **窄屏优先**：所有尺寸以 360dp 宽手机为基准；在 320dp 设备上把网格卡片缩到 148dp，仍保持 2 列。
2. **触控目标**：所有图标按钮 ≥ 40dp，Tab 项 ≥ 44dp，与 Material 规范一致。
3. **状态栏沉浸**：内容从状态栏下方开始，不自定义状态栏样式；Android 6.0+ 使用 `SYSTEM_UI_FLAG_LIGHT_STATUS_BAR` 或 Edge-to-Edge 保持浅色图标在深色背景上可见。
4. **暗色一致性**：全部使用 `bg-base` / `bg-surface` / `bg-elevated` 三层表面，不使用纯黑 `#000000`。
5. **强调色单一**：仅绿色 `#34c759` 用于「下载 / 激活 / 开关」，避免多色干扰。
